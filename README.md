# סלסלה 🎶

רשימת הקניות המשותפת של שמואל וטליה. בזמן אמת, עם סלסולים.

- **אפליקציה:** נבנית אוטומטית ומתפרסמת ב-GitHub Pages
- **APK לאנדרואיד:** נבנה אוטומטית בכל עדכון, זמין בעמוד ה-Releases
- **סנכרון:** Firebase Firestore, עובד גם בלי קליטה ומסתנכרן כשחוזרים לאוויר
- **פרטיות:** הנתונים שמורים בפרויקט Firebase פרטי, מוגנים בקוד בית סודי שלא נמצא בקוד הזה

נבנה באהבה, בשביל הבית. 🧺
